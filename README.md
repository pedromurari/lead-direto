# Lead Direto — Instituto DespertaMENTE

Landing page de captação de leads para a formação em Psicanálise Clínica Integrativa do Instituto DespertaMENTE.

## Tecnologias

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Como rodar localmente

Pré-requisito: Node.js e npm instalados ([instale com nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
# Instalar as dependências
npm i

# Iniciar o servidor de desenvolvimento
npm run dev
```

## Build

```sh
npm run build
```

## Deploy

O projeto está configurado para deploy na Vercel (ver [vercel.json](./vercel.json)).
